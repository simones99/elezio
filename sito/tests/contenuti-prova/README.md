# Contenuti di prova

Contenuti finti per il test di fumo Playwright (`tests/smoke.spec.ts`): il sito si costruisce da qui con `ELEZIO_CONTENUTI=tests/contenuti-prova`. Partiti, documenti, citazioni e schede sono inventati e non vanno mai pubblicati; il sito vero legge solo `../contenuti`.

Copre i casi che il test controlla: una scheda verificata con due citazioni (Alfa), una posizione assente verificata (Beta), una bozza che non deve comparire (Gamma). I temi sono copiati da `contenuti/temi.yaml`.
