# elezio

App/sito per le elezioni italiane: programmi elettorali, confronto tematico, quiz di orientamento, risultati e finanziamenti. La ricerca di settore è in `ricerca/repository_open_source_politica_italiana.md` (locale, non versionato). Visione in `docs/VISION.md`, roadmap in `docs/ROADMAP.md`, mappa delle decisioni: GitHub issue #1 (`wayfinder:map`).

## Agent skills

### Issue tracker

Issues live in GitHub Issues for simones99/elezio (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles, with two renamed: `ready-for-agent` is `ready-for-coding`, `ready-for-human` is `needs-action`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` at the root and ADRs in `docs/adr/`. See `docs/agents/domain.md`.
